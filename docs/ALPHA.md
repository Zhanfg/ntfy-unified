# Alpha 0.0.1 acceptance

Base: MIT-licensed Rubix Studios Ntfy App, pinned commit b1035e69fd1b4d67df4490994c2cf289790cce64.

## First desktop Alpha
- Install an unsigned Linux/Windows CI artifact and launch the window.
- Subscribe to ntfy.sh or a trusted self-hosted server.
- Publish to a controlled test topic and receive a native notification.
- Confirm persistence across restart and recovery after network interruption.
- Measure binary/package size and startup footprint.

## Deliberately deferred
- Android/iOS builds and platform background delivery
- Svelte migration, GPL/Telegram source reuse and particle animations
- Signed/public release and automatic app updates

Do not claim runtime acceptance until an installer has been tested on a device.
